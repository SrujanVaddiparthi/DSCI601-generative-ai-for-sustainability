# Dataset acquisition and preparation

The raw Surface Defect Inspection (SDI) Dataset is intentionally not stored in this Git repository.

## Official dataset source

- Dataset repository: https://github.com/boschresearch/The-Surface-Defect-Inspection-Dataset
- Dataset archive in that repository: `SDI_DATASET_v1.zip`
- Associated paper: *Defect Transfer GAN: Diverse Defect Synthesis for Data Augmentation* (BMVC 2022)
- BMVC paper page: https://bmvc2022.mpi-inf.mpg.de/445/
- arXiv: https://arxiv.org/abs/2302.08366
- Dataset license: CC BY-SA 4.0

The Bosch repository is archived and read-only, but it remains the authoritative public source for the dataset, its documentation, citation, and license. Review the upstream license and citation instructions before reuse or redistribution.

## Dataset used in this project

This project used the Type-A product surface and three labels:

- normal
- scratches
- spots

The curated research subset used in the final study contained:

- 702 normal images
- 344 scratch images
- 181 spot images

These are curated project counts, not the complete raw counts in the upstream dataset.

## Expected upstream structure

After downloading and extracting the official dataset, the Type-A data should provide a normal-image directory and defect directories split across train, validation, and test partitions. The preparation scripts expect the equivalent of:

```text
A_ok/
A_nok/
├── train/
│   ├── scratches/
│   └── spots/
├── val/
│   ├── scratches/
│   └── spots/
└── test/
    ├── scratches/
    └── spots/
```

Folder names should be checked against the downloaded dataset version before running the scripts.

## Prepared structure used by training

The prepared Type-A subset is expected at:

```text
data/
└── prepared_A/
    ├── normal/
    ├── scratches/
    └── spots/
```

Prepare or inspect the data using:

```text
../data_preparation/prepare_sdi_subset.py
../data_preparation/quick_check.py
```

The preparation script samples or copies images into the class-oriented layout used by the cDCGAN experiments. Review its configuration and paths before running it.

## Procedurally generated controlled scratch data

Exp7 and Exp8 used a procedurally generated diagnostic dataset rather than the real SDI images. It contains simple grayscale backgrounds and controlled line-like scratches whose angle, position, length, width, and intensity are generated by code.

Recreate it using:

```text
../experiments/04_controlled_simple_scratch/generate_simple_scratch_dataset.py
```

The generated procedural data is excluded from Git because it is reproducible from the script.

## Storage policy

Do not commit the raw SDI dataset, prepared image folders, generated procedural datasets, or full training outputs to this repository.

Representative results are retained in Git. Full data and outputs belong in approved project storage and the private handover archive.
