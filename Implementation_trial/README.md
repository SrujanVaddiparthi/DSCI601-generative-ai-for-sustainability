# Implementation and learning workflow

This directory separates tutorial/prototype work from experiments used to support the final research conclusions.

## `learning_experimentation`

Preserves the MNIST cDCGAN and TensorFlow CycleGAN learning stages. These helped establish conditioning, PatchGAN, cycle consistency, and the distinction between full-image generation and image-to-image translation.

## `cDCGAN_SDI`

Contains the main project implementation:

- SDI preparation
- exploratory notebooks
- three-class baseline
- normal-versus-scratch track
- normal-versus-spot track
- controlled procedural scratch experiments
- selected result grids and run summaries
